# shared/components/

Generic presentational components (class 3 in the
[component classification](../../../../docs/design-system/components.md#1-classification--choose-the-first-source-that-fits)).
Use a native element or Bootstrap markup first; add a component only when it adds behaviour,
accessibility wiring or a reused composition.

| Component | Example of |
| --- | --- |
| [button/](button/button.md) | Attribute-selector wrapper of a native element with a loading state |
| [loading-spinner/](loading-spinner/loading-spinner.md) | Delayed, announced loading indicator |
| [empty-state/](empty-state/empty-state.md) | Component built on a global SCSS pattern with content projection |
| [card/](card/card.md) | Guidance: when *not* to create a component |
| [modal/](modal/modal.md) | Guidance: dialog implementation choices |
