# styles/utilities/

Helper classes for the **standalone** entry: `.ds-visually-hidden`,
`.ds-visually-hidden-focusable`, `.ds-truncate` ([_helpers.scss](_helpers.scss)).

In the Bootstrap profile, use Bootstrap's equivalents and add new utilities through Bootstrap's
Utility API (`$utilities` in `vendors/bootstrap/_index.scss`) so all utilities share one naming
scheme and responsive variants.
