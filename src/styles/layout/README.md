# styles/layout/

Layout CSS that Bootstrap does not provide.

| File | Entry | Provides |
| --- | --- | --- |
| [_app-shell.scss](_app-shell.scss) | both | `.ds-shell` application frame (header, sidebar persistent ≥ lg / off-canvas below, main, footer, backdrop); logical properties only |
| [_primitives.scss](_primitives.scss) | both | `.ds-auto-grid`, `.ds-measure`, `.ds-section`, `.ds-container-query` |
| [_containers.scss](_containers.scss) | standalone | `.ds-container`, `.ds-container-fluid` (Bootstrap profile uses `.container`) |

Docs: [layout-and-responsive.md](../../../docs/design-system/layout-and-responsive.md).
