# styles/tokens/

Canonical token definitions (Sass maps, no CSS). Seeded from `config/_project.scss`.

| File | Tokens |
| --- | --- |
| [_palette.scss](_palette.scss) | Level 1 primitives: generated 50–950 palettes; `palette()` |
| [_semantic.scss](_semantic.scss) | Level 2 contract: semantic color names + contrast pairs |
| [_components.scss](_components.scss) | Level 3: component tokens (button, input, card, overlay, badge, table) |
| [_typography.scss](_typography.scss) | Families, scale, weights, line heights, letter spacing, text roles |
| [_spacing.scss](_spacing.scss) | 4 px scale and semantic aliases |
| [_sizing.scss](_sizing.scss) | Breakpoints, containers, content widths, shell sizes, control heights, icons |
| [_shape.scss](_shape.scss) | Radius scale and roles, border widths, focus-ring geometry |
| [_elevation.scss](_elevation.scss) | Shadows, elevation roles, z-index layers |
| [_motion.scss](_motion.scss) | Durations and easings |

Docs: [design-tokens.md](../../../docs/design-system/design-tokens.md).
