# playground/src/styles/

Playground-only global SCSS. Defines **no new token values**.

| File | Purpose |
| --- | --- |
| `_token-exports.scss` | Re-exports Sass-only tokens (palettes, breakpoints, containers, content widths, icon sizes, contrast pairs) as `--pg-*` custom properties so pages can display them |
| `_docs.scss` | Documentation page patterns (`.pg-page`, `.pg-section`, `.pg-demo`, `.pg-token`, `.pg-code`) built from tokens |
