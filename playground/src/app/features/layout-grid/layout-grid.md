# playground/src/app/features/layout-grid/

Layout and grid page: breakpoints with the active one highlighted as the window resizes, container
widths, Bootstrap grid examples, `.ds-auto-grid`, gap utilities, `.ds-measure` and content widths.

- Files: `layout-grid-page.ts/.html/.scss`
- Data source: breakpoints, containers and content widths from `--pg-*` exports; the active breakpoint is computed from `window.innerWidth`.
