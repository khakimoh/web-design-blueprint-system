RTL and LTR

Blueprint styles use logical properties, so they need no direction overrides. Bootstrap's physical utilities are flipped by postcss-rtlcss in the build, so both directions work in one bundle and can be switched at runtime — for the whole page or a single element.

Page direction

Current: {{ preferences.direction() === 'rtl' ? 'RTL (lang="fa")' : 'LTR (lang="en")' }}. Switching moves the sidebar, flips alignment and mirrors directional icons.
